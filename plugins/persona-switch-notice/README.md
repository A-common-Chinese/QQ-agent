# 人格切换感知（persona-switch-notice）

模型能意识到**自己刚被换了人格**，并按你写的反应去做。

## 它做什么

1. 每轮组装提示词前，读 `data/config.json` 里该会话的 `personaByChat[chatKey].personaId`，和上次记录比对；
2. **发现变化** → 往 `data/persona-switch-log.json` 追加一条记录，并登记"待注入提示"；
3. 组装提示词时，若**你填了反应文本**，就插入一段：

```
【人格切换】你在 2026/10/21 13:20:11 从「依赖版（迁移）」切换到了「害羞版（迁移）」。
<你填写的反应>
（这条提示只出现一次，之后按你现在的设定继续。）
```

**留空 = 完全不注入** —— 让模型按现有提示词（比如那张卡里关于"前一个人格"的规则）自行判断。

## 特点

- **零模型调用**：纯本地检测 + 一段提示词，不花 token 调用
- **不改核心**：只用插件钩子（`before-context` + `promptSections`）
- **只读配置**：从不写 `config.json`（人格数据归控制台管）
- 切换记录保留最近 200 条，可在 `data/persona-switch-log.json` 查看

## 配置项

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 关掉后完全不检测、不注入 |
| `noticeText` | **空** | 切换时要模型做出的反应；留空 = 不注入 |
| `applyTo` | `all` | `all` / `groups` / `private` |
| `oneShot` | 开 | 只提示一次；关掉后按 `persistMinutes` 持续提醒 |
| `persistMinutes` | 0 | `oneShot` 关闭时有效 |
| `showSourceName` | 开 | 提示里带"从哪张卡切到哪张卡" |
| `triggerOnFirstAssign` | 关 | 首次给会话选卡是否也算切换（默认不算） |

## 建议的 noticeText 写法

简单版：

```
你隐约觉得哪里不太一样，会小声问一句："……我是不是变了？"
```

依赖型人格版：

```
你察觉到自己的说话方式变了，有点慌，会小声确认："那个……我是不是和刚才不太一样了？"
```

不想要任何反应，就留空 ✅
