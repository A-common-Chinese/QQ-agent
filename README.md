# QQ Agent（桌面端）

![平台](https://img.shields.io/badge/platform-Windows%20%7C%20Electron-lightgrey)
![版本](https://img.shields.io/badge/version-v0.7.3-blue)
![测试](https://img.shields.io/badge/tests-33%20suites%20(npm%20test)-brightgreen)
![许可](https://img.shields.io/badge/license-MIT-green)

一个跑在你自己电脑上的 QQ 群聊机器人：装完双击启动，在控制台填好官方机器人凭据和模型 Key 就能用。事件驱动 + 无状态会话架构，每次处理的 token 成本恒定可控；所有操作都在图形控制台里完成，不用碰命令行。

> ⚠️ **仅供个人学习与自用。** 本项目基于 QQ 开放平台的**官方机器人**接口，不涉及协议破解；若你自行接入第三方协议端，由此产生的账号风险由你自行承担。详见 [ACCEPTABLE_USE.md](./ACCEPTABLE_USE.md) 与下方[合规说明](#合规说明)。

> **这是一个 fork。** 上游是 [K0nd1us/QQ-agent](https://github.com/K0nd1us/QQ-agent)，本仓库是 **[A-common-Chinese/QQ-agent](https://github.com/A-common-Chinese/QQ-agent)**，当前版本 `v0.7.3`（测试版）。

## 这是什么

| 能力 | 说明 |
|---|---|
| 像真人一样混群 | 被 @ 或被叫到时回话，平时看心情插嘴；会发文字、表情包、戳一戳，会引用、会 @ 人，也知道什么时候该闭嘴 |
| 记住每个群友 | 长期记忆 + 记忆卡，按 QQ 号记人、按群记事，下次聊天自然带上；控制台里随时可看、可改 |
| 说得像谁由你定 | 人格卡系统：每个会话独立选卡，共用段 + 本卡特有段 + 回复示例 + 按需场景 |
| 看得懂图、上得了网 | 视觉模型直接看消息里的图片；内置 6 家搜索服务（含免 Key 的 Bing 网页解析） |
| 花多少看多少 | 每次调用的 token 与成本精确记录，按天 / 按会话 / 按模型统计，缓存命中率、峰谷分时都标出来 |
| 零编程门槛 | 配置全在控制台点选：白名单从 QQ 里直接勾群，模型从目录里点选 |
| 能指挥本机 DSH | QQ 里发 `/dsh <指令>`，交给本机 DeepSeek Harness 执行并回传结果 |
| 接 QQ | **QQ 开放平台官方机器人**（合规通道）；也兼容自行安装的**非官方协议端**（可选，风险自负） |

**技术架构**（沿用上游，未改动主干）

1. 群聊消息持续写入本地 JSON 存档，每条带时间与已读状态；
2. 有新消息时新开一个独立会话，提示词 = 静态系统提示（人设 / 规则 / 策略）+ 存档摘要 + 本次新消息；
3. 会话结束即弃置，LLM 层面零历史，单次成本不随聊天量膨胀；
4. 处理期间新来的消息只写存档，本轮结束后发现未读就自动再开一轮，直到清空；
5. 长期信息走记忆工具与记忆卡持久化，跨运行生效。

整体组成：QQ 侧走**官方开放平台机器人**（AppID/AppSecret + WebSocket 网关）；大脑是任意 OpenAI 兼容 API；桌面壳是 Electron（托盘常驻、开机自启、关窗不退出）；控制台是零框架原生 HTML/CSS/JS。安全边界上，工具天然绑定会话、发送有白名单与限频、联网抓取带 SSRF 防护。

## 接入方式：QQ 官方机器人

| 项 | 说明 |
|---|---|
| 协议 | QQ 开放平台官方 API（合规） |
| 账号风险 | 不因协议违规被封；风险只在内容合规与平台规则 |
| 前置 | 在开放平台创建机器人 → 个人认证 → 拉进自己是群主的群 |
| 群消息范围 | 默认只推 @；全量消息需群主在手机 QQ 授权「接收全量消息」 |
| 主动消息 | 需群主授权「主动推送消息」，1000 条/群/日；被动回复 5 分钟内有效 |
| 能力 | 群/单聊收发、被动回复、主动发言（群主授权）、群管理（禁言/成员/黑名单） |
| 缺口 | 无拍一拍 / 贴表情 / 改群名片 / 撤回他人消息（官方无接口） |

**怎么配**：控制台 → 「QQ 接口」页 → 选「官方机器人」→ 填 AppID / AppSecret（只存本机，页面脱敏）→ 环境（正式·沙箱）→ 群消息模式（全量·仅 @）→ 测试 → 设为当前通道 → 重启。

- 官方通道的 openid 不用手抄：卡片下方「最近收到的会话」点「加入白名单」
- 群主授权「接收全量消息」后，机器人才会收到非 @ 的群消息

## 可选：其他协议端

如果你**自行**在本机安装并登录第三方协议端（非官方实现），也可以在「QQ 接口」页配置连接地址与令牌，作为另一种接入方式。

- 本仓库**不附带、不下载、不代管**任何第三方协议端，也不代管其登录态
- 该方式可能违反平台服务协议，**风险由使用者自行承担**（建议用小号）
- 控制台只做检测 / 启停 / 卸载与连接配置，不提供安装引导

## 这个 fork 改了什么

> 完整清单在历史版本说明里；这里只列主要方向。

- **接入方式**：以官方机器人为核心；非官方协议端改为**可选外部依赖**（不随包分发）
- **记忆卡系统**：群卡 / 个人卡 / 通用卡 / 话题卡，记忆整理流水线，个人卡「通用印象 + 私聊印象」，约定带时间戳与期限（短期/长期/永久）
- **语义触发**（预览，默认关闭）：把「该不该主动接话」做成可观察、可分群配置的流水线（语义分 → 分群阈值 → 可选的模型判定 → 数据面板）
- **通道映射**：把官方 openid 会话与非官方协议端的群/账号会话绑成同一逻辑会话（软绑定白名单、7 天可撤销）
- **消耗提示**：用量页/设置页把「哪些操作会多花 token」讲清楚
- **启动动画**：每天首次 + 每次更新后播放一次，可关
- **DSH 桥**：QQ 里 `/dsh` 指挥本机 DeepSeek Harness
- **运维**：开机联网守卫、夜间停止、会话结束钩子、桌面端更新检查
- **修复**：记忆卡「事实」渲染、删除卡片误报、身份映射、判定面板等

## 隐私说明

- 所有配置、聊天存档、记忆、日志都在本机 `data/` 目录，不上传服务器
- 只有两类出站请求：你自己的模型 API（以及可选联网搜索）、QQ 官方开放平台
- 出站内容带隐私过滤（密钥/令牌/手机号/身份证/银行卡/本机路径等默认打码或拒发）
- 安装包不含任何 API Key / AppSecret

## 合规说明

**结论：不是反向代理，也不是中转。** 每个部署者装在自己电脑上、填**自己的** API Key，程序在本机直连模型官方端点；安装包不含 Key，也没有对外提供接入点。

判定标准三个问题：谁的 key？有没有共享？有没有对外提供入口？——本项目均为「用户自己填、本机直连」。

### 模型侧

- 把模型接进 QQ 机器人属于平台允许的下游集成
- 安装包不带 Key、不提供托管/共享额度，每个部署者自己填
- 群里对外服务时，内容审查义务在部署者（本项目内置出站过滤与安全模式可复用）

### 腾讯侧（官方机器人）

《QQ开放平台服务协议》4.2 条明确支持 AIGC 机器人；义务集中在「模型服务有备案」「生成内容有标识」「不编造虚假信息」。官方通道是平台正式支持的业务形态。

### 关于第三方协议端

若自行接入非官方协议端，可能触及平台服务协议中「不得通过非官方授权的第三方软件登录或使用服务」的条款，处罚对象是**你的账号**。本项目不附带、不下载、不代管此类程序，相关风险由使用者自行承担。

## 快速开始

1. 安装并启动 → 控制台打开（`http://127.0.0.1:3210`）
2. 「QQ 接口」→ 官方机器人 → 填 AppID / AppSecret → 设为当前通道 → 重启
3. 「模型」→ 填任意 OpenAI 兼容 API（地址 / Key / 模型）
4. 「聊天」→ 把群加入白名单（官方通道从「最近收到的会话」直接加）
5. 在群里 @ 机器人试试

（可选）自行安装非官方协议端后，在「QQ 接口」里配置为另一种接入方式。

### 扩展（插件 / Skill）

沿用上游机制：`plugins/`、`skills/` 目录，控制台可启用/禁用/配置；插件通过能力（capability）挂到核心流程上。

## 目录结构

```

skills/        Skill（可选）
```
