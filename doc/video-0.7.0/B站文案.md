QQ Agent DSH v0.7.0 更新：新增官方 QQ 机器人接入。

- 以前：SnowLuma / OneBot，非官方协议，有封号风险
- 现在：可切 QQ 开放平台官方机器人，不再因协议违规被封
- 两种通道的白名单 / 日志 / 记忆互相独立，随时切换

群消息默认只推 @ 的，全量需要群主在手机 QQ 授权；
个人主体只能把机器人加进自己是群主 / 管理员的群。
