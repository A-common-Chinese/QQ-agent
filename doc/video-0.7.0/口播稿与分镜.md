# v0.7.0 介绍视频 · 口播稿与分镜

> 目标时长：约 110–125 秒（9 段）
> 语速：正常偏慢一点，段间留 0.4s
> 配音：剪映「文本朗读」即可（无需外部 TTS）

## 分镜表

| 段 | 画面 | 口播 |
|---|---|---|
| S1 | 黑底大字：「AI 群友，号还在吗？」→ 切控制台 | 给 QQ 群挂一个 AI 机器人，最怕的不是不好用，而是号没了。以前只能靠第三方协议，现在有了官方通道。 |
| S2 | QQ 接口 → OneBot 卡片（群号打码） | 这是之前的方案：SnowLuma 加 OneBot。玩法最全，但它走的是非官方协议，协议一改、风控一紧，就有封号风险。 |
| S3 | 切官方机器人卡片，填 AppID，AppSecret 输入框（password 遮挡） | 现在多一个选择：QQ 开放平台的官方机器人。在控制台的 QQ 接口页，填你自己机器人的 AppID 和 AppSecret。 |
| S4 | 点「测试鉴权」绿字 → 点「设为当前通道」→ 重启 | 点一下测试鉴权，能通过就说明凭据有效。然后设为当前通道，重启应用。 |
| S5 | 手机/群里 @ 机器人 → 秒回；切回控制台看会话 | 到群里 @ 它一下，就能看到会话创建、回复发出。走的是官方被动回复通道，不需要额外授权。 |
| S6 | 点右上角 ⓘ 说明弹窗，逐条划过 | 有一点要说清楚：官方通道没有拍一拍、贴表情、改群名片；群消息默认只推 @ 的，要收全部消息，需要群主在手机 QQ 里授权。个人主体也只能加自己是群主的群。 |
| S7 | 顶栏胶囊（绿）→ 点 ▾ 展开状态菜单 → 两套白名单/日志目录 | 两种通道的白名单、日志、记忆完全独立。顶栏这个胶囊会按通道变蓝或者变绿，四个点告诉你哪一步还没通。 |
| S8 | Release 页 / QQ 接口页全景 | 装最新版，在 QQ 接口里选官方机器人就能用。原来用 SnowLuma 的同学，什么都不用改。 |
| S9 | GitHub 上游仓库页（K0nd1us/QQ-agent）+ 本项目 README 的致谢段 + star 一下 | 最后说一下来源。这个项目是从上游 K0nd1us 的 QQ-agent 分出来的，底子是上游打的；SnowLuma 和 OneBot 这些开源协议实现，也帮了大忙。官方机器人通道是这次新加的，但真正让这件事成立的，是上游和社区，谢谢他们。 |

## 口径提醒

- 不说「绝对不封 / 免封」，说「不再依赖第三方协议，不会因协议违规被封；内容违规仍会被平台处理」
- 录屏前：群号/QQ 号打码；不要露出开放平台里的 Secret 明文；关掉桌面通知
- 剪掉等待/加载过程（编译、重连），保留关键反馈（测试鉴权通过、消息回复）
