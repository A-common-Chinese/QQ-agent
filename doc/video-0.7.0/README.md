# v0.7.0 介绍视频素材包

## 文件清单

| 文件 | 用途 |
|---|---|
| `口播稿与分镜.md` | 9 段逐字稿 + 每段对应画面（含致谢段） |
| `短版-60秒-口播.md` | 竖屏短版台词（5 句，含致谢） |
| `字幕-估算.srt` | 字幕文件（按 5 字/秒估算，导入剪映后可微调） |
| `时长估算.md` | 每段预计时长表 |
| `B站封面-1146x717.png` | 封面（B 站 16:9 规格） |
| `B站文案.md` | 标题 / 简介（含来源致谢）/ 标签 / 审核注意 |
| `segments.json` | 分段文本（贴进剪映字幕条用） |

## 配音（已确定：用剪辑软件）

剪映流程：
1. 新建项目 → 导入录屏与封面
2. 「文本」→ 新建字幕 → 把 `segments.json` 里每段贴进去（一段一条）
3. 选中字幕 → 「文本朗读」→ 选音色（推荐「知性女声/清晰男声」）→ 生成配音
4. 用 `字幕-估算.srt` 的时间轴对齐；按朗读实际长度微调每条字幕起止
5. 语速建议 1.0–1.1，段间留 0.4s 空白

## 录屏清单（按分镜）

1. 控制台 → QQ 接口，OneBot 卡片（群号打码）
2. 切「官方机器人」→ 填 AppID → AppSecret 输入框（password 已遮挡）→ 测试鉴权绿字
3. 点「设为当前通道」→ 重启
4. 群里 @ 机器人 → 秒回
5. 点右上角 ⓘ 说明弹窗
6. 顶栏胶囊（绿）+ 点 ▾ 展开状态菜单
7. 存档里官方会话
8. Release 页
9. 上游仓库页（K0nd1us/QQ-agent）致谢镜头

## 录制前检查

- [ ] 群名/群号/QQ 号已打码（或换测试群）
- [ ] 开放平台后台页面不要入镜（避免 Secret）
- [ ] 桌面通知已关闭
- [ ] 窗口接近 16:9（1920×1080 附近），UI 不糊
- [ ] 演示前确认：机器人已授权、@ 能收、能回（先试一遍）
