# 竖屏短版（约 60–75 秒）

**1.** 给 QQ 群挂一个 AI 机器人，最怕的不是不好用，而是号没了。以前只能靠第三方协议，现在有了官方通道。

**2.** 现在多一个选择：QQ 开放平台的官方机器人。在控制台的 QQ 接口页，填你自己机器人的 AppID 和 AppSecret。

**3.** 到群里 @ 它一下，就能看到会话创建、回复发出。走的是官方被动回复通道，不需要额外授权。

**4.** 装最新版，在 QQ 接口里选官方机器人就能用。原来用 SnowLuma 的同学，什么都不用改。

**5.** 最后说一下来源。这个项目是从上游 K0nd1us 的 QQ-agent 分出来的，底子是上游打的；SnowLuma 和 OneBot 这些开源协议实现，也帮了大忙。官方机器人通道是这次新加的，但真正让这件事成立的，是上游和社区，谢谢他们。
